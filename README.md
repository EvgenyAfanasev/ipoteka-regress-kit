# ipoteka-regress-kit

Набор инструментов для взыскания с бывшего супруга 1/2 доли платежей по ипотечному
кредиту в порядке регресса (п. 2 ст. 325 ГК РФ): юридическая стратегия, генераторы
досудебной претензии и искового заявления в формате docx, автоматический расчёт
процентов по ст. 395 ГК РФ по ключевой ставке ЦБ и госпошлины.

Для ситуации: квартира куплена в браке в ипотеку, оба супруга — созаёмщики
(солидарная ответственность), развод оформлен, раздела имущества не было, платит
один — и хочет вернуть половину.

> ⚠️ **Дисклеймер.** Проект — вспомогательный инструмент и конспект стратегии,
> а не юридическая консультация. Нормы и пороги меняются: перед подачей документов
> сверяйте их с действующими редакциями (ГК РФ, СК РФ, ГПК РФ, НК РФ, ФЗ-229)
> и при спорных ситуациях консультируйтесь с адвокатом.

## Быстрый старт

```bash
python3 -m venv .venv                     # один раз
.venv/bin/pip install -r requirements.txt

.venv/bin/python scripts/pretenziya.py --init   # создать .env из .env.example
$EDITOR .env                                    # заполнить постоянные данные

.venv/bin/python scripts/pretenziya.py    # досудебная претензия -> docx
.venv/bin/python scripts/isk.py           # исковое заявление -> docx
```

Значения из `.env` подставляются как умолчания (Enter — принять, ввод —
переопределить), недостающее скрипты спрашивают интерактивно. Все даты/суммы
валидируются.

## Состав проекта

```
docs/superpowers/specs/2026-08-19-regress-ipoteka-design.md  — стратегия (спека):
    правовой каркас, этапы, сроки, шаблоны претензии/иска, чек-листы, риски
scripts/pretenziya.py   — генератор досудебной претензии (docx)
scripts/isk.py          — генератор искового заявления (docx)

requirements.txt        — python-docx
```

## Сценарий использования (сжатый таймлайн)

1. **Пока платит** — собрать пакет документов, вести реестр платежей (платить
   банку всегда: при 3+ месяцах просрочки банк вправе потребовать долг досрочно).
2. **Перестала платить (D-день)** — копить 2–4 месяца фактов, затем претензия
   заказным с описью (срок ответа 30 дней).
3. **Иск** — мировой судья при цене иска ≤ 50 000 ₽, выше — районный
   (п. 4 ч. 1 ст. 23 ГПК РФ); рассмотрение ~1–2 мес.
4. **Вступление в силу + исполнительный лист** — ~1 мес.
5. **ФССП или банк напрямую** — арест счетов обычно через 5–15 рабочих дней
   после возбуждения производства. Итого от D-дня до первых списаний ~4–9 мес.

Подробно: этапы, нормы, таймлайн, риски и чек-листы — в спеке.

## Что делают скрипты

| Скрипт | Считает / генерирует |
|---|---|
| `pretenziya.py` | 1/2 долю каждого платежа, итоги; docx-претензия по шаблону из спеки |
| `isk.py` | Проценты по ст. 395 ГК (посуточно, с учётом смен ставки и високосности), цену иска, госпошлину (ст. 333.19 НК, шкала с 08.09.2024), проверку подсудности (мировой/районный); docx-иск по ст. 131–132 ГПК с таблицей расчёта и приложениями |
| `cbr_rate.py` | Ключевая ставка ЦБ по дням с официального SOAP-сервиса DailyInfo (`KeyRateXML`), без ключей; кэш в `tmp/` (работает офлайн); ставка выходного/праздника = ставка последнего рабочего дня |

Начало начисления процентов — на выбор: со дня после каждого платежа
(рекомендуется) или со дня после вручения претензии (консервативно).
При недоступности ЦБ — офлайн-режим: единая ставка вручную или иск без
расчётной суммы процентов.

## Конфигурация `.env`

Один профиль на оба генератора; формат и назначение каждого ключа — в
`.env.example`. Группы:

| Группа | Ключи | Использование |
|---|---|---|
| Стороны | `SENDER_*`, `RECIPIENT_*` | оба скрипта |
| Брак | `MARRIAGE_*`, `DIVORCE_*` | оба скрипта |
| Кредит | `BANK_NAME`, `CONTRACT_*`, `SENDER_ACCOUNT`, `APARTMENT_ADDRESS`, `UNPAID_FROM` | оба скрипта |
| Платежи | `PAYMENTS` (`дата:сумма; …` — дописывать каждый месяц) | оба скрипта |
| Иск | `COURT_NAME`, `PLAINTIFF_*`, `DEFENDANT_*`, `CLAIM_*` | `isk.py` |

`.env` содержит персональные данные и добавлен в `.gitignore` — в репозиторий
попадает только `.env.example`.

## Правовая база (каркас)

- **п. 2 ст. 325 ГК РФ** — регресс исполнившего солидарное обязательство;
- **п. 1, 3 ст. 39 СК РФ** — общие долги делятся пропорционально долям (равным);
- **ст. 34 СК РФ** — граница: регресс только по платежам после развода;
- **ст. 395 ГК РФ**, п. 48 Пленума ВС РФ № 7 от 24.03.2016 — проценты по ключевой
  ставке ЦБ по день фактического исполнения;
- **ст. 23, 28, 131–132 ГПК РФ** — подсудность, форма и приложения иска;
- **ст. 333.19 НК РФ** — госпошлина (шкала с 08.09.2024);
- **ФЗ-229 «Об исполнительном производстве»** — лист в банк (ст. 8) или ФССП,
  аресты и списания, повторное предъявление листа.
